One-time setup

FileView needs permission to access local files. Browser security requirement — takes 30 seconds.

Chrome Setup
1
Open Chrome Extensions
Type in the address bar (click to copy):
chrome://extensions
Or: ☰ Menu → More Tools → Extensions
2
Find FileView → click Details
Scroll to FileView — Syntax Highlighter and click Details.
3
Enable "Allow access to file URLs"
Turn on this toggle on the details page:
Allow access to file URLs
4
Open any local file
Drag a file onto Chrome or press Ctrl+O. Done — highlighting is automatic.
⚠
Why is this required? Chrome blocks extensions from local files by default for security. FileView only reads — never modifies or uploads your files.
Microsoft Edge Setup
1
Open Edge Extensions
edge://extensions
Or: ☰ Menu → Extensions → Manage Extensions
2
Click Details for FileView
Find FileView — Syntax Highlighter and click Details.
3
Enable "Allow access to file URLs"
Allow access to file URLs
4
Open any local file
Drag a file onto Edge or press Ctrl+O.
ℹ Edge is Chromium-based — steps are identical to Chrome, only the URL differs.
Firefox Setup
1
Use the Firefox manifest
Rename manifest_firefox.json → manifest.json in the extension folder.
2
Load as temporary add-on
about:debugging
Click This Firefox → Load Temporary Add-on → select manifest.json
3
Fix file:// access if needed
If files still don't highlight:
about:config
Find privacy.file_unique_origin → set to false
4
Open any local file
Press Ctrl+O or drag a file onto Firefox.
⚠
Note: Temporary add-ons are removed on Firefox restart. For permanent install, the extension needs to be signed via addons.mozilla.org.
Safari Setup

⚠ Safari requires Xcode conversion

Safari Web Extensions are macOS-only and need to be built via Xcode.


  1. Install Xcode from the Mac App Store
  2. Run: xcrun safari-web-extension-converter /path/to/file-viewer-ext
  3. Open the Xcode project → Build (⌘B)
  4. Safari → Settings → Extensions → Enable FileView
  5. Websites tab → allow file:// URL access

Tip: Chrome or Edge on macOS is much easier to set up.
